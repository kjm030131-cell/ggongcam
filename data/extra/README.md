# 직접 모은 학습 사진

꽁줍이 비전 데이터 탭에서 내보낸 ZIP(`ggongcam_dataset_날짜.zip`)을 이 폴더에 그대로 올리면 된다.
GitHub 웹에서 이 폴더를 열고 Add file → Upload files 로 끌어다 놓고 Commit 하면,
학습 워크플로가 자동으로 다시 돌아 다음 모델에 들어간다.

- 한국 바닥(보도블록, 아스팔트, 배수구 주변), 에쎄 같은 슬림, 아이코스, 릴 스틱 사진이 특히 도움이 된다.
- 사진을 누르고 박스를 직접 고친(확인 표시) 사진이 가장 좋다.
- 꽁초 없는 바닥 사진도 섞으면 헛감지가 줄어든다.
